# El Concurso del Año — juego de fans (Grok Bot)
Cuatro, con Dani Martínez. Fases: desconocido, pistas (famoso, zoom, familiar, evento, foto, canción, recuerdo), revelación y final con tableta. Modos diario y noche.

Menú: Jugar, Entrenamiento, Opciones, Normas, Créditos, Historia. Voces con Piper (español de España).
Lo inventado o adaptado está marcado en la pantalla **Normas** de la app. Concursantes inventados.

Una producción de Iker.
